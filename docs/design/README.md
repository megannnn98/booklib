# Редизайн витрины Booklib — макеты и UX-решения

Направление: BookLore (визуальный стиль, сайдбар, карточки, панель фильтров) +
Komga (плотность, переключение сетка/список для больших коллекций) + Kavita
(мобильный UX). Исходный код референсов не копировался — только визуальные и
UX-ориентиры.

## Файлы

- `desktop.html` — статичный макет каталога 1600×1000. Параметры: `?view=list`,
  `?theme=light`, `?details=1`.
- `mobile.html` — две рамки телефона 390×844 (сетка в тёмной теме, список в
  светлой), внутри — тот же `desktop.html`.
- `mockup.js` — выдуманные книги: кириллица, технические PDF, даташиты,
  альбомные слайды, карточки без обложки. Обложки рисуются SVG на лету.
  **Реальные названия из личной библиотеки в git не попадают** — это опись,
  как и `config/taxonomy.json`.
- `screenshots/` — рендеры макетов.

Макеты подключают боевой `src/booklib/api/static/style.css`, а не свою копию:
дизайн и реализация не могут разойтись.

## UX-решения

1. **Основной клик по карточке не изменён.** Host desktop — папка в файловом
   менеджере (`/api/open`), trusted LAN и гость — выбор формата (`/api/files`).
   Панель подробностей открывается только отдельной кнопкой ⓘ, её клик делает
   `stopPropagation`. Если роль неизвестна (не ответил `/api/status`), UI
   ведёт себя как гость — fail closed.
2. **Сайдбар:** «Все книги» / «Недавно добавленные» (= `sort=added`, без нового
   API), затем разделы со счётчиками и **поиском по разделам**; список
   прокручивается отдельно от страницы, поэтому 100+ разделов не ломают
   навигацию. Внизу — настройки, словарь тегов, «Установить». На desktop
   сайдбар сворачивается (☰, запоминается в `localStorage`), на mobile —
   выдвижная панель с overlay.
3. **Верхняя панель:** поиск (`/` — фокус), сортировка, «Фильтры» с бейджем
   числа, Grid/List, плотность, тема, «Обновить» (только admin). На mobile —
   две строки: меню, поиск, тема / сортировка, фильтры, вид, плотность,
   обновить; все цели 44×44.
4. **Контекст:** название вида, число найденных, чипы всех активных фильтров
   (раздел, запрос, теги, форматы) с удалением по одному и «Сбросить всё».
5. **Фильтры** собраны в одну панель: формат (тумблеры со счётчиками из
   `/api/formats`) и теги с поиском. Desktop — правая панель, mobile —
   полноэкранная.
6. **Сетка:** обложка всегда `object-fit: contain` на тёмной подложке в обеих
   темах (сканы и даташиты белые). Название — 2 строки (полное — в `title`,
   в подробностях и в списке), бейджи форматов в цвете. Заглушка — «корешок»
   с оттенком от названия, названием, автором и форматом. Плотность:
   стандартная / компактная (2 → 3 колонки на mobile, ~168 → ~124 px на
   desktop).
7. **Список:** колонки обложка / название / автор / раздел / форматы / размер;
   заголовки «Название» и «Размер» переключают серверную сортировку. На mobile
   таблица складывается в строки: миниатюра, название, автор, форматы и
   размер, действия справа.
8. **Пагинация:** страницы по 120 через `offset/limit`, подгрузка при
   приближении к концу (IntersectionObserver) плюс кнопка «Показать ещё» для
   клавиатуры и как запасной путь. Ответ устаревшего запроса (фильтр сменили,
   пока он летел) отбрасывается по номеру запроса. Каталог целиком в браузер не
   грузится.
9. **Hover — не единственный путь:** кнопки на карточке на desktop появляются
   при наведении или фокусе, на тач-экранах видны всегда.
10. **Mobile:** диалоги — нижние листы, подробности — на весь экран, поля
    ввода 16px (без зума iOS), safe area, нет горизонтального скролла
    (проверено: `scrollWidth == 390`).
11. **Темы:** тёмная — исходная палитра (`#14161a / #1c1f25 / #262a32 /
    #d8a657`). Светлая — тёплая «бумажная», акцент затемнён до `#8a5d12`
    (≥4.5:1 на белом). По умолчанию тема берётся из `prefers-color-scheme`,
    выбор хранится в `localStorage` и применяется inline-скриптом в `<head>`
    до первой отрисовки.
12. **Состояния:** скелетон при загрузке, пустой результат с «Сбросить
    фильтры», ошибка API с «Повторить», баннер «библиотека не смонтирована».
