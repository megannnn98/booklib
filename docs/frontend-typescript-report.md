## Выполненные шаги

1. Тулчейн уже был закоммичен: TypeScript strict + noUncheckedIndexedAccess,
   esbuild, Vitest/jsdom, npm lock, make-цели и frontend job CI.
2. Чистые хелперы уже были перенесены. Сверены исходные CJS-тесты из истории:
   8 кейсов UI + 12 кейсов тегов сохранены; TS-набор содержит 10 + 12 кейсов.
   Фиксированный порядок query и незакодированная `section=*` проверяются отдельно.
3. API-клиент уже был перенесён. Проверена граница X-Booklib. При завершении
   уточнены DTO удаления/объединения тегов и замены тегов книги по backend-коду.
4. Состояние и фильтры уже были закоммичены; завершено подключение DOM-модулей.
5. Завершены статус, рескан, сборка приложения и запуск PWA. Подключены карточки,
   навигация, каталог, файлы, подробности, редактор, фильтры, словарь тегов,
   настройки, тема, плотность, sidebar и поиск. Статус приходит до карточек;
   отказ статуса оставляет интерфейс гостевым. В исходниках нет `any`.
6. HTML загружает единый IIFE `static/app.js`; старые отдельные JS-хелперы
   удалены. SW поднят с v8 до v9, список ассетов обновлён. Офлайн-страница и
   стратегии кэширования не менялись. CI пересобирает и сравнивает бандл с git.
   Бандл хранится в Python-пакете; Node на сервере не нужен.
7. Обновлены CLAUDE.md, README.md и docs/ai-context/architecture.md.

Дополнительно устранена гонка: ошибка старого запроса «ещё» не показывает тост
и не разблокирует кнопку, пока первая страница нового поиска ещё загружается.

## TDD и мутации

Продолжение началось с незавершённых DOM-модулей и тестов предыдущего агента.
Историю red → green каждого уже написанного модуля восстановить нельзя;
строгое соблюдение TDD для всей миграции не заявляется.

Новые наблюдаемые циклы:

- PWA: тест установки упал на `expected false to be true` для
  `beforeinstallprompt.defaultPrevented`, затем прошёл после реализации.
- Гонка пагинации: тест упал на `moreBtn.disabled` (`false` вместо `true`),
  затем прошёл после проверки requestSeq в обработчике ошибки.
- Незавершённый тест статуса ожидал пустую дату при непустом last_scan;
  ожидание исправлено на локализованную дату, соответствующую старому JS.

Мутации выполнялись на копии в `/tmp/booklib-mutations`; рабочий код не ломался.

| Мутация | Покрасневшие проверки |
|---|---|
| Удалить X-Booklib из API-клиента | 15 тестов api.test.ts, включая все привилегированные ручки |
| Добавлять X-Booklib ко всем GET | 8 тестов публичных ручек, включая files/download |
| Выбирать действие карточки по local вместо hostDesktop | 3 теста cards.test.ts: trusted LAN и Enter/Space |
| Добавить method="dialog" в настоящую форму настроек | settings.test.ts: запрет dialog submission |
| Переставить sort перед section | 2 теста ui_helpers.test.ts, включая фиксированный порядок |
| Кодировать звёздочку как %2A | 2 теста ui_helpers.test.ts, включая wildcard |

Первая мутация формы пережила исходный набор: jsdom не воспроизводит нативное
implicit submission. Добавлена явная проверка method настоящей формы; повторная
мутация её ломает. Этот предел jsdom сохраняется для ручной браузерной проверки.

Логи: `/tmp/booklib-mutation-results.log`, `/tmp/booklib-mutations/*.log`,
`/tmp/booklib-python-full.log`, `/tmp/booklib-python-pwa.log`.
