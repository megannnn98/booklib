# scripts/

Одноразовые инструменты, которые не входят в пакет.

## build_taxonomy.py — не в репозитории

Разовая раскладка библиотеки по разделам живёт локально и в git не попадает:
её тело — это поимённые списки книг, то есть та же опись личной библиотеки,
что и `config/taxonomy.json`.

Скрипт проходит по всем карточкам каталога и раскладывает их по разделам
таблицами подстрок, после чего пишет `config/taxonomy.json` в формате
`config/taxonomy.example.json`:

```python
KEY_RULES = [("подстрока ключа", "Раздел"), ...]  # проверяются первыми
DIR_RULES = [("папка", "Раздел"), ...]  # затем по папке
TITLE_OVERRIDES = {"подстрока": ("Название", "Автор")}
```

Требование к результату — 100% покрытие: если после раскладки осталась карточка
без раздела, скрипт падает и печатает список. Проверка без записи: `--check`.

Без `taxonomy.json` каталог работает: разделы проставятся по `config/rules.json`,
непознанное уедет в «Новое», а поправить можно прямо в веб-интерфейсе (кнопка ✎).
